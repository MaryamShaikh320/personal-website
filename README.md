# A little website about me ✨

Welcome to my personal website! This project is a space where I showcase my experiences, projects, technical interests, and growth as a student and aspiring engineer.

Built using HTML, CSS, and JavaScript, the website reflects my journey through programming, robotics, and technology. It highlights my involvement in competitive robotics, including VEX IQ and FIRST Robotics Competition (FRC), as well as projects that allow me to explore concepts in software development, computer vision, and engineering.

Beyond showcasing my technical experience, I wanted to create a website that reflects my personality and interests. I incorporated interactive elements, custom layouts, and visual design choices to make the experience more engaging while continuing to develop my front-end development skills.

Please note that this project is in progress.
